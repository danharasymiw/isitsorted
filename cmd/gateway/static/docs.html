API reference

JSON API

POST /is-sorted

Submit a list for sort verification. Returns a job ID. No auth required.

Request

POST /is-sorted
Content-Type: application/json

{
  "list": [1, 3, 2, 4],
  "order": "asc"
}

Response

202 Accepted

{ "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890" }

curl

JOB=$(curl -s -X POST https://isitsorted.ca/is-sorted \
  -H "Content-Type: application/json" \
  -d '{"list":[1,2,3],"order":"asc"}' )

curl https://isitsorted.ca/is-sorted/$(echo $JOB | jq -r .id)

JSON API

Poll for a result

Every submission is processed asynchronously by a worker. Poll the job ID for status and result, or stream updates over SSE. No auth required.

Poll

GET /is-sorted/{id}
200 OK

{
  "id": "a1b2c3d4-...",
  "status": "done",
  "sorted": true
}

Stream (SSE)

GET /is-sorted/{id}/events

Emits status events ( queued, processing, done, error) and closes the connection once the job finishes.

Upload a file

GET /upload
200 OK

{
  "id": "a1b2c3d4-...",
  "upload_url": "https://...presigned..."
}

PUT your list (newline or comma-separated) to upload_url, then trigger the check:

POST /upload/{id}/check
Content-Type: application/json

{ "order": "asc" }
202 Accepted

{ "id": "a1b2c3d4-..." }

curl

RESP=$(curl -s https://isitsorted.ca/upload)
ID=$(echo $RESP | jq -r .id)

curl -X PUT "$(echo $RESP | jq -r .upload_url)" \
  --data-binary @list.txt

curl -X POST https://isitsorted.ca/upload/$ID/check \
  -H "Content-Type: application/json" \
  -d '{"order":"asc"}'

JSON API

POST /is-sorted

Returns JSON. No auth required.

Request

POST /is-sorted
Content-Type: application/json

{
  "list": [1, 3, 2, 4],
  "order": "asc"
}

Response

200 OK

{ "sorted": true }

curl

curl -X POST https://isitsorted.ca/is-sorted \
  -H "Content-Type: application/json" \
  -d '{"list":[1,2,3],"order":"asc"}'
